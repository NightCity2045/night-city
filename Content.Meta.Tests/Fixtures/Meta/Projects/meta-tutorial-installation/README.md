# 5. Install and recover

5. Установка и восстановление.

Use a claimed META host, the physical NCMetaTemperatureSensor and NCMetaAlarm, connected by real data cables. Bind training-sensor and training-alarm; bind training-data to the host's own private FileStore; approve only the declared methods and an explicit unattended policy if needed. Lost power, route or grants stop native commands. A missing or stale sensor is displayed as unavailable.

The isolated fixture sends 31, 28 and 24 °C and checks exact native command traces. Hysteresis keeps the alarm requested at 28 °C and clears it at 24 °C. Successful alarm transitions are persisted atomically in training/last-transition.txt. The MUI settings form accepts integer limits 1–80 with low strictly below high; opening a panel does not grant control.

Use the native Software installer and Installation recovery entries for deployment, stop, previous-image rollback and permission review. This package does not install software or approve grants itself.
