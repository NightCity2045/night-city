# META example projects

`catalog.json` is the versioned inventory consumed by template import. Each entry points to a project directory with `manifest.json`, normalized META source files and an executable `meta.test.json` fixture. Import copies files into a new private project; it never grants device access or starts software.

Manifest schema 1.0 contains `version`, `id`, localized `name`/`nameRu`, `packageName`, `packageVersion`, `languageVersion`, `bytecodeVersion`, `runtimeAbi`, `rootModule`, `files`, `startMode`, `bindings` and `testFixture`. Each source entry contains its destination virtual `path`, canonical `sourcePath` and SHA-256 of normalized UTF-8 bytes. Paths are relative and cannot contain parent traversal. `testFixture` follows `MetaTestFixture` in `Content.Meta.Testing`; it is runnable against the isolated VM without ECS authority.

Each binding declares a deployment `slot`, native `capability`, exact `contractHash` and `requiredScopes`. These describe requirements. A real deployment must select an owned, reachable, powered and compatible physical device through the normal installation flow. A slot string, a manifest or a successful fixture does not provide authority. Fixtures contain process-local fake devices and cannot move or modify live entities.

The first fifteen packages are the fifteen normative programs from Specification XVII. `meta-example-library` adds the two-file reusable smoothing example. Dashboard, garage, factory, laboratory and functional implant packages extend this inventory. Expected output and command traces are stored in each fixture, including ordered events and delayed host completions. The file example tests the API contract in isolation; durable storage crash guarantees require separate server/database integration tests.

Vehicle, drone, industrial and optics examples require explicitly compatible hardware. The conveyor additionally needs a real load sensor interlock. Drone waypoint names come from its authorized mission map. Optics require the physical LowLight module and functioning power/neural/thermal state. Manual takeover, sensor loss and command failures remain native device decisions.

Compatible variants are declared in `Resources/Prototypes/_NC/Meta/domains.yml`. Claim a device, then use its META workspace verb. `NCMetaSupraEcu` keeps the existing vehicle controls; ECU mode requests only cap native torque. `NCMetaPatrolDrone` uses physical NPC steering and a replaceable cell. Select it with `NCMetaCommissioningTool`, then visit and select `NCMetaWaypointA` / `NCMetaWaypointB` to add the two named mission points. The same tool can bind a separately owned load cell to a conveyor. `NCMetaConveyor` already includes its own local load cell and stops when its sensor or control lease becomes stale.

`NCMetaCyberOptics` is an actual installable cyberoptics variant. After native surgical installation and power-bus commissioning, the wearer can claim it and open its workspace through their body verbs. Manual clear/low-light controls take priority over guest firmware. Removing or disabling the module invalidates its old commands.

Functional variants are declared under `Resources/Prototypes/_NC/Meta/Functional/`. The `meta-example-functions` template uses `FunctionalController` on a real ToolHand, MantisBlade, Biomonitor, Sandevistan or Kerenzikov module. Only its actual wearer can claim the installed module and opt into automation. The template renews an already active mode; native manual controls, a stopped process or the three-second lease end its authority. Repeated enable requests retain the original native burst duration, cooldown and startup charge. Integral tools still need a free hand and use native interactions; deploying a blade does not create an attack. Biomonitor pulse performs its real one-shot wearer reading and energy debit. Compile on a suitable external computer before installing software on the implant.

`NCMetaClinicalController` starts with an empty physical reservoir and automation disabled. Its owner uses it on a nearby patient to bind the native context, reviews the physical reservoir/tool setup, and explicitly enables automation. `MedicalMonitor.patient()` returns an opaque reference valid only for that process and patient context. `snapshot` uses the existing capability-filtered diagnostic builder and does not expose hidden organ identifiers. `DosingController.dose(patient,key)` requests the configured hardware dose; guest code supplies neither a reagent, an amount nor an entity ID. `ProcedureController.startSelectedStep(patient,key)` invokes the practitioner's already selected native surgical step with their actual active-hand tool and the normal DoAfter interruption rules.

Clinical keys are ASCII letters/digits/underscore/hyphen, at most 64 characters. Reusing a key with a different owner, device, patient epoch or dose configuration cannot replay or reveal another operation. `operationStatus(key)` returns its durable receipt. A receipt becomes `Committing` before any physical effect; timed procedures then become `Running` and settle from the native result. Incomplete records after interruption become `OutcomeUnknown` (or `Rejected` if physical commit had never begun). Guest code must not blindly repeat an uncertain action under a new key. World snapshots drain admitted journal mutations, and procedure effects recheck patient identity, power, grant and installation generation immediately before native resolution.

The delivery and equipped-shot packages extend this inventory to 23 packages. Cargo requires NCMetaCargoDrone (or the equipped variant), a visible nearby physical item, and a commissioned `loading` waypoint. The equipped-shot template runs once, manually, and selects its first visible mobile contact in a controlled range. Its native receipt confirms a real projectile, never a hit or damage. No example auto-starts or supplies live ownership, fire authority or a target. Contacts have a two-second process/device/control epoch lifetime; stored measurements stay frozen. Cargo uses native hands/storage/locks/capacity and the equipped mount uses real cartridges, rotation, shot blockers and cooldown. Interrupted journal commits reconcile conservatively, with no automatic replay.
