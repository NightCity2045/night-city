# Owned door control

Install through Software installer, bind owned-door to your reachable physical door and approve only door.control and door.observe. The owner-only MUI uses the actual user's native action context. Opening the window does not grant door access. Applied command results and later state events are distinct; the app never treats Opening as Open. Native access, power, bolts and collision checks remain in force.

The isolated fixture injects a real ABI-shaped Closed observation. Native physical door scenes test the actual actuator and denied commands.
