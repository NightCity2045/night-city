# Archived directional vehicle source art

These 4 by 2 sheets were used by the retired eight-direction 3/4 presentation. They remain as design history and are not production inputs.

Production vehicles now use one orthographic top-down source per model from `Docs/Design/SourceArt/VehicleTopDown/`. The vehicle nose points up, and RobustToolbox rotates the single frame continuously with the entity transform.

Files named after Cyberpunk vehicles are original AI-assisted fan-art renditions by Astro (2026). No game texture was copied.
