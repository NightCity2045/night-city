# Vehicle source art

These transparent 4×2 sheets are the approved high-resolution sources for the generated RSI fleet. Production files are built with `Tools/_NC/VehicleArt/build_vehicle_rsi.py`.

Files named after Cyberpunk vehicles are original AI-assisted fan-art renditions by Astro (2026). No game texture was copied.
