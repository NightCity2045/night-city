# Vehicle driver HUD source art

The three PNG files in this directory are the approved high-resolution source images generated for the Night City 2045 vehicle HUD. `Tools/_NC/Vehicle/build_vehicle_hud_assets.py` crops and reduces them into the runtime textures under `Resources/Textures/_NC/Vehicle/Hud/`.

The art was generated with the built-in OpenAI image generation tool. The prompts requested isolated transparent, front-facing Cyberpunk RED cockpit modules in worn black metal with restrained amber and cyan accents. Separate passes produced the dashboard atlas, an empty H-pattern console, and a spoke-free steering wheel suitable for generated rotation frames. No external game or vehicle artwork was used as an image input.
