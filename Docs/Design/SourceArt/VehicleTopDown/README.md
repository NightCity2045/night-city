# Production top-down vehicle sources

Each PNG contains one transparent orthographic top-down vehicle with its nose pointing up. One vehicle uses one source file. Build production RSIs with `Tools/_NC/VehicleArt/build_vehicle_rsi.py`; do not assemble directional sheets.

Files named after Cyberpunk vehicles are original AI-assisted fan-art renditions by Astro (2026). No game texture was copied. Their use is subject to `LicenseRef-CDPR-Fan-Content` and the CD PROJEKT RED Fan Content Guidelines.
