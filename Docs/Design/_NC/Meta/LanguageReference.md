# Язык META: справочник по синтаксису

Версия языка: **1.0** · компилятор `nc-meta-1.0.0` · расширение исходных файлов `.meta` · кодировка UTF-8.

Этот документ описывает язык META так, как его разбирает и проверяет компилятор из `Content.Meta/Language` (`Lexer.cs`, `Parser.cs`, `Syntax.cs`, `MetaCompiler*.cs`). Если текст расходится с проектной спецификацией `Docs/Design/_NC/Meta/Specification.md`, правдой считается компилятор; расхождения собраны в [разделе 17](#17-расхождения-со-спецификацией-и-оговорки). Все программы в блоках ` ```meta ` с полной структурой (`module …`) были скомпилированы настоящим компилятором при подготовке документа, а блоки ` ```meta-error ` отвергаются с указанным кодом.

> **Что здесь не описано.** Рантайм (gas, планировщик, байткод, сохранение состояния) и игровая интеграция описаны в спецификации и в `Docs/Design/_NC/Meta/*.md`. Язык разметки интерфейса `Mui` (XML-диалект в `Content.Meta/Mui`) — отдельный язык, к синтаксису META не относится.

## 1. Обзор языка

META — статически типизированный императивный язык небольшого размера:

- **Типизация статическая и строгая.** Неявных преобразований нет: ни между `int` и `float`, ни между числом и строкой, ни между `enum` и числом. Ошибка типа обнаруживается при компиляции.
- **Нет `null`.** Отсутствие значения выражается `option<T>`, ошибка — `result<T>`.
- **Нет исключений, классов, наследования, указателей, пользовательских дженериков, замыканий, функций как значений, перегрузок.**
- **Только фигурные скобки.** Тела `if`, `while`, `for`, функций и ветвей `match` всегда в `{ }`.
- **Присваивание — инструкция, а не выражение.** `a = b = 1` невозможно. Тернарного оператора, `++`, `+=` нет.
- **Выражения вычисляются слева направо**, `&&` и `||` — с сокращением.
- **Вызовы только позиционные.** Именованные аргументы существуют лишь у `new Struct(поле: значение, …)`.
- **Работа с устройствами — через выданные интерфейсы (capability).** Программа не может получить устройство по строке или числу: она объявляет `link` и получает непрозрачный handle от сервера.

Минимальная программа:

```meta
module examples.hello;
import meta.system;

fn main() -> void {
    system.log("META: программа запущена");
}
```

## 2. Структура файла и проекта

### 2.1 Порядок элементов в файле

Каждый `.meta`-файл — один модуль. Порядок фиксирован:

1. Ровно одна директива `module имя.модуля;`
2. Ноль или больше директив `import …;`
3. Объявления верхнего уровня в любом порядке (`const`, `let`, `var`, `fn`, `struct`, `enum`, `link`, `watch`).

```meta
module vendor.demo;           // 1. модуль
import meta.system;           // 2. импорты
import meta.text as txt;

const LIMIT: int = 10;        // 3. объявления
fn main() -> void { system.log(txt.fromInt(LIMIT)); }
```

Объявления внутри модуля видимы друг другу независимо от текстового порядка: функцию можно вызывать до её объявления, тип — использовать до `struct`.

### 2.2 Имя модуля

`module a.b.c;` — квалифицированное имя из идентификаторов через точку. Правила:

- имена `meta` и `meta.*` зарезервированы за стандартной библиотекой; пользовательский модуль с таким именем — ошибка `E301`;
- два файла с одним именем модуля — ошибка `E302`;
- один файл — один модуль, один проект — до 64 файлов.

### 2.3 Корневой модуль, библиотеки, `main`

Проект собирается с **корневым модулем** (root module). Только в нём разрешены:

- `link` и `watch`;
- функция `main`.

В остальных модулях (библиотеках) такие объявления дают ошибку `E309`. Библиотека может содержать функции, типы, константы и приватное состояние, а capability получает только параметром функции.

`main` необязательна (программа из одних `watch` допустима), но если она есть, она имеет вид:

```
fn main() -> void { … }
async fn main() -> void { … }
```

Параметры или другой возвращаемый тип — ошибка `E214`.

### 2.4 Манифест проекта

Рядом с исходниками лежит `manifest.json`; он не часть языка, но задаёт сборку:

```json
{
  "version": "1.0",
  "id": "meta-example-hello",
  "packageName": "examples.hello",
  "packageVersion": "1.0.0",
  "languageVersion": "1.0",
  "bytecodeVersion": "1.0",
  "runtimeAbi": "1.0",
  "rootModule": "examples.hello",
  "files": [ { "path": "main.meta", "sourcePath": "…", "sha256": "…" } ],
  "startMode": "Manual",
  "bindings": []
}
```

`rootModule` указывает корневой модуль; `path` файла — виртуальный путь без `\`, `:`, `..` и ведущего `/` (иначе `E307`).

## 3. Лексика

### 3.1 Пробелы и комментарии

Пробел, табуляция, `\n`, `\r` — разделители. Комментарии:

```text
// до конца строки
/* блок; вложенность не поддерживается */
```

Незакрытый `/* … ` — ошибка `E101`.

### 3.2 Идентификаторы

`[A-Za-z_][A-Za-z0-9_]*` — **только ASCII**. Регистр значим (`engine` ≠ `Engine`). Единственный символ `_` — ключевое слово (шаблон-«подчёркивание»), как имя использовать нельзя.

Внутри строк и комментариев допускается любой Unicode, в том числе русский текст.

### 3.3 Ключевые слова

Использовать как идентификаторы нельзя:

| Группа | Слова |
|---|---|
| Структура | `module` `import` `as` `pub` `link` `watch` `fn` `async` `struct` `enum` |
| Переменные | `let` `var` `const` |
| Управление | `if` `else` `while` `for` `in` `return` `break` `continue` `match` `yield` `await` |
| Значения | `true` `false` `some` `none` `ok` `err` `new` `_` |
| Типы | `void` `bool` `byte` `int` `float` `string` `array` `list` `map` `option` `result` |
| Зарезервировано на будущее | `null` `class` `throw` `catch` `spawn` `eval` `unsafe` `typeof` `using` |

Слова из последней строки не имеют конструкций в версии 1.0; их использование приводит к ошибке разбора, а не к скрытому поведению.

### 3.4 Целочисленные литералы

```text
42      1_000_000      0xFF      0x7f_ff
```

- десятичные цифры либо `0x` + шестнадцатеричные цифры (префикс только строчный `0x`);
- `_` допустим **только между цифрами** (не в начале, не в конце, не два подряд);
- знак — отдельный унарный оператор: `-5` это `-` применённый к `5`;
- литерал за границей `int64` — `E204`; исключение: `-9223372036854775808` допустимо;
- по умолчанию литерал имеет тип `int`; если из контекста ожидается `byte` и значение лежит в 0–255, он получает тип `byte` (иначе `E204`).

### 3.5 Литералы с плавающей точкой

```text
110.0     2.5     1e3     2.5e-2     1_0.0_5     6E+2
```

- обязательны либо цифры по обе стороны точки, либо экспонента; `1.` и `.5` недопустимы (`E105`);
- вещественное значение должно быть конечным; `−0` нормализуется в `+0`.

### 3.6 Строки

```text
"обычная строка"
"кавычка \" обратная косая \\ перевод строки \n табуляция \t возврат \r"
"символ Unicode: \u{1F680}"
```

- допустимые escape: `\"`, `\\`, `\n`, `\r`, `\t`, `\u{шестнадцатеричные 1–6 цифр}`; любой другой — `E107`;
- неэкранированный перевод строки, управляющий символ или незакрытая кавычка — `E106`;
- **интерполяции нет**; строки склеиваются оператором `+`, числа переводятся `text.fromInt` / `text.fromFloat`;
- строка не нормализуется (Unicode хранится как есть, в UTF-8);
- максимальная длина — 65 536 байт (`E405`).

### 3.7 Логические значения и единичное значение

`true`, `false` — тип `bool`. Пустые скобки `()` — единственное значение типа `void` («unit»).

### 3.8 Операторы и разделители

Двухсимвольные (лексер берёт самое длинное совпадение): `->` `=>` `==` `!=` `<=` `>=` `&&` `||` `<<` `>>`.

Односимвольные: `{ } ( ) [ ] ; , : . + - * / % ! ~ & | ^ < > =`.

Любой другой символ — `E100`. Число, сразу за которым идёт буква (`12abc`), — `E105`.

## 4. Типы

### 4.1 Список типов

| Тип | Значения и особенности |
|---|---|
| `void` | единственное значение `()`; результат функций без полезного значения |
| `bool` | `true` / `false`; числа в `bool` не приводятся |
| `byte` | 0–255; арифметики не имеет, для вычислений переводится в `int` |
| `int` | знаковое 64-битное целое; переполнение — аварийная остановка процесса |
| `float` | IEEE 754 binary64, только конечные значения; NaN и ±∞ невозможны |
| `string` | неизменяемая последовательность Unicode-символов, сравнение порядковое |
| `array<T>` | массив фиксированной длины, элементы изменяемы |
| `list<T>` | изменяемый список переменной длины |
| `map<K, V>` | словарь; ключ — `int`, `byte`, `bool`, `string` или `enum`; порядок обхода — порядок вставки |
| `option<T>` | `some(значение)` или `none` |
| `result<T>` | `ok(значение)` или `err(Error)` |
| `enum` | пользовательский или библиотечный перечислимый тип |
| `struct` | пользовательская запись с именованными полями |
| capability | неподделываемый handle устройства (только через `link`) |
| opaque | непрозрачная ссылка на игровой объект (`SessionRef`, `PatientRef`, …) |
| native DTO | запись, пришедшая от устройства (`EngineState`, `DoorState`, …); поля только для чтения |

### 4.2 Запись типов

```text
int                       float                    string
array<float>              list<string>             map<string, int>
option<int>               result<string>           result<void>
list<array<int>>          map<int, list<string>>
Reading                   vehicle.EngineState      implants.FunctionKind
```

- параметры контейнера обязательны: `array<T>`, `list<T>`, `option<T>`, `result<T>` — один; `map<K, V>` — два;
- `>>` на закрытии вложенных типов (`list<list<int>>`) компилятор разбирает как две закрывающие скобки;
- имя пользовательского типа можно писать коротким (`Reading`), если он объявлен в этом модуле или экспортирован импортированным модулем, и полным/через алиас (`vehicle.EngineState`);
- `Error`, `ErrorCode`, `SampleStamp` доступны без импорта (они из `meta.system`).

`result<T>` всегда несёт ошибку типа `Error` — отдельного параметра для типа ошибки нет.

### 4.3 Ограничения на типы

- **Ключ `map`**: только `int`, `byte`, `bool`, `string`, `enum` (`E218`).
- **Рекурсивные типы запрещены**, в том числе через контейнеры: `struct Node { children: list<Node>; }` — `E219`. Деревья представляют массивом узлов и индексами.
- **Размер `struct`**: не более 64 полей, плоский размер до 4 КиБ (`E217`), вложенность типов до 16 уровней (`E219`).
- Capability, opaque-ссылки и ожидающие операции нельзя сохранять в пользовательское состояние и передавать в сообщения.

```meta-error:E219
module test.program;
struct Node { children: list<Node>; }
fn main() -> void { }
```

### 4.4 Преобразования

Неявных нет. Явные функции — в модуле `meta.numeric`:

| Функция | Результат |
|---|---|
| `numeric.toFloat(int)` | `float` (может округлить большие числа) |
| `numeric.toInt(float)` | `result<int>`: округление к нулю, `OutOfRange` при переполнении |
| `numeric.toByte(int)` | `result<byte>`: ошибка, если вне 0–255 |
| `numeric.byteToInt(byte)` | `int` |
| `numeric.absInt(int)`, `numeric.absFloat(float)` | модуль числа |

Строка ↔ число: `text.fromInt`, `text.fromFloat`, `text.parseInt`, `text.parseFloat` (последние два возвращают `result`).

```meta-error:E201
module test.program;
var t: float = 110;
fn main() -> void { }
```

## 5. Объявления верхнего уровня

### 5.1 Глобальные `const`, `let`, `var`

```meta
module test.program;
const VERSION: string = "1.0";       // константа, значение считает компилятор
let limit: float = 110.0;            // неизменяемая привязка процесса
var counter: int = 0;                // изменяемое состояние процесса
pub const MAX_RPM: int = 7000;       // экспортируется
fn main() -> void { counter = counter + 1; }
```

- тип **обязателен**, инициализатор **обязателен** (неинициализированных переменных и «нулей по умолчанию» нет);
- `pub` допустим только для `const` (`pub let`/`pub var` — `E215`);
- глобальные `let`/`var` принадлежат процессу: после перезапуска создаются заново, автоматически не сохраняются;
- в инициализаторах нельзя вызывать функции и использовать `await` (`E212`); циклические зависимости между глобальными значениями — `E213`. Подробности — в [разделе 12](#12-константы-и-инициализаторы-глобальных-значений).

### 5.2 Функции

```text
[pub] [async] fn имя(параметр: Тип, …) -> ТипРезультата { … }
```

```meta
module test.program;

pub fn clamp(value: float, low: float, high: float) -> float {
    if (value < low) { return low; }
    if (value > high) { return high; }
    return value;
}

async fn pause() -> void { yield; }

fn main() -> void {
    let x = clamp(130.0, 0.0, 100.0);
}
```

- возвращаемый тип обязателен; для «ничего» пишут `void`;
- вызовы позиционные, число и типы аргументов должны совпасть (`E227`/`E201`);
- параметры неизменяемы; чтобы менять значение, скопируйте его в `var`;
- перегрузок, значений по умолчанию, переменного числа аргументов, вложенных функций нет;
- допустима рекурсия и взаимная рекурсия (глубина ограничена рантаймом);
- не-`void` функция должна завершаться `return` на **всех** путях (`E214`); после `while` требуется `return`, компилятор не доказывает бесконечность цикла;
- в функции `-> void` `return;` в конце необязателен;
- публичная функция не может иметь в сигнатуре непубличный тип (`E230`).

### 5.3 `struct`

```meta
module test.program;
pub struct Reading {
    temperatureC: float;
    rpm: int;
}
fn main() -> void {
    let sample = new Reading(temperatureC: 108.0, rpm: 3200);
}
```

- каждое поле — `имя: Тип;` с обязательной `;`;
- у структур нет методов, конструкторов-функций и значений полей по умолчанию;
- значение создаётся только выражением `new Имя(поле: значение, …)` — [раздел 7.9](#79-конструктор-new);
- копируется по значению; поля-коллекции копируют ссылку на ту же коллекцию.

### 5.4 `enum`

```meta
module test.program;
pub enum Health { Normal, Warning, Critical, }   // завершающая запятая допустима
fn main() -> void { let h = Health.Warning; }
```

- хотя бы один вариант, варианты разделяются запятой;
- обращение — `Тип.Вариант` (при необходимости с алиасом: `vehicle.EngineMode.Safe`);
- числа в enum и обратно не приводятся.

### 5.5 `link`

```text
link имя: ТипCapability = "имя-слота";
```

```meta
module test.program;
import meta.doors;
link door: Door = "front-door";
fn main() -> void { }
```

См. [раздел 10](#10-link-и-watch-работа-с-устройствами). `link` не может быть `pub`.

### 5.6 `watch`

```text
[async] watch имяLink.событие(параметры) { … }
```

См. [раздел 10](#10-link-и-watch-работа-с-устройствами). `watch` не может быть `pub`.

### 5.7 Видимость: `pub`

Экспортируются только `pub fn`, `pub struct`, `pub enum`, `pub const`. Глобальные `let`/`var`, `link` и `watch` наружу не видны.

`async` без `fn`/`watch` (`async struct`) — ошибка разбора.

## 6. Инструкции (statements)

Все инструкции, кроме блоков и управляющих конструкций, заканчиваются `;`.

### 6.1 Локальные переменные

```meta
module test.program;
fn main() -> void {
    let a = 10;                       // неизменяемая привязка, тип выведен: int
    let b: float = 2.5;               // тип указан явно
    var total: int = 0;               // изменяемая
    const STEP: int = 5;              // константа, тип обязателен
    total = total + STEP;
}
```

- `let` — нельзя переприсвоить; `var` — можно; `const` — значение вычисляет компилятор;
- тип локального `let`/`var` может быть выведен из инициализатора; для `const` тип обязателен (`E203`);
- `let` **не делает коллекцию неизменяемой**: элементы `array`/`list` можно менять;
- пустой литерал `[]`, `none`, `err(…)` без ожидаемого типа вывести нельзя (`E203`) — укажите тип:

```meta
module test.program;
fn main() -> void {
    let empty: array<int> = [];
    let nothing: option<int> = none;
}
```

```meta-error:E203
module test.program;
fn main() -> void { let x = none; }
```

### 6.2 Области видимости и затенение

Область: модуль → функция/обработчик → блок → ветвь `match` / итерация `for`. Повторное объявление в той же области — ошибка; **затенение переменной внешнего блока тоже запрещено** (`E211`), равно как совпадение имени локальной переменной с алиасом импорта, глобальной переменной или `link`:

```meta-error:E211
module test.program;
fn main() -> void { let x = 1; { let x = 2; } }
```

Поле `struct` может совпадать по имени с локальной переменной — доступ к нему явный (`x.поле`).

### 6.3 Присваивание

```text
цель = выражение;
```

Допустимые цели:

| Цель | Условие |
|---|---|
| `имя` | переменная объявлена `var` (локальная или глобальная) |
| `выражение.поле` | родитель — присваиваемая цель; поле не только для чтения |
| `коллекция[индекс]` | `array` или `list`; индекс типа `int` |

```meta
module test.program;
struct Point { x: int; y: int; }
fn main() -> void {
    var p = new Point(x: 1, y: 2);
    p.x = 10;
    let values: array<int> = [3, 7, 9];
    values[0] = 4;        // допустимо даже для let: меняется содержимое
}
```

Присваивание `let`-переменной, полю DTO от устройства или элементу `map` через `[]` — `E210`:

```meta-error:E210
module test.program;
fn main() -> void { let x: int = 1; x = 2; }
```

Типы цели и значения должны совпасть. Выход индекса за границы — остановка процесса во время выполнения; для «может не быть» используйте `map.get` → `option`.

### 6.4 Выражение как инструкция

`выражение;` допустимо только если оно имеет тип `void`. Отбросить значение другого типа нельзя (`E240`) — его надо присвоить, вернуть или разобрать через `match`:

```meta-error:E240
module test.program;
fn f() -> int { return 1; }
fn main() -> void { f(); }
```

### 6.4.1 Предупреждение W101

`let` с типом `result<…>`, которая нигде не читается, даёт предупреждение `W101` (не ошибка): вероятно, результат операции забыли проверить.

### 6.5 `if` / `else`

```meta
module test.program;
fn sign(x: int) -> int {
    if (x < 0) {
        return -1;
    } else if (x == 0) {
        return 0;
    } else {
        return 1;
    }
}
fn main() -> void { let s = sign(5); }
```

Условие обязано быть `bool` (`E202`), скобки вокруг условия и фигурные скобки тел обязательны. Допускается цепочка `else if`.

### 6.6 `while`

```meta
module test.program;
fn main() -> void {
    var i: int = 0;
    while (i < 10) {
        i = i + 1;
        if (i == 3) { continue; }
        if (i == 8) { break; }
    }
}
```

`break` и `continue` вне цикла — `E233`.

### 6.7 `for … in`

```meta
module test.program;
fn main() -> void {
    let values: array<float> = [92.0, 96.0, 100.0];
    var sum: float = 0.0;
    for (let value in values) {
        sum = sum + value;
    }
}
```

- форма строго `for (let имя in выражение) { … }`;
- перебирать можно только `array<T>` и `list<T>` (иначе `E234`), в порядке индексов; тип переменной выводится;
- выражение-коллекция вычисляется один раз;
- менять длину перебираемого `list` внутри цикла нельзя (рантайм остановит процесс с `CollectionModified`); значения элементов менять можно;
- словарь обходят через `map.keys()` (возвращает `array<K>`).

### 6.8 `match`

```meta
module test.program;
import meta.system;
fn main() -> void {
    let value: option<int> = some(3);
    match (value) {
        some(x) => { system.log("есть"); }
        none => { system.log("нет"); }
    }
}
```

Подробно — [раздел 8](#8-option-result-и-match).

### 6.9 `return`

```text
return;                 // для void
return выражение;       // для остальных типов
```

Тип выражения должен совпасть с объявленным типом результата. В `watch` `return` завершает только текущий обработчик.

### 6.10 `yield`

`yield;` — добровольная уступка планировщику; разрешён в любой функции и обработчике. См. [раздел 11](#11-асинхронность-async-await-yield).

### 6.11 Блок

`{ … }` — самостоятельная инструкция со своей областью видимости.

## 7. Выражения

### 7.1 Приоритеты и ассоциативность

От сильного к слабому:

| № | Операторы | Ассоциативность |
|---|---|---|
| 1 | вызов `f(…)`, поле `.имя`, индекс `[…]` | слева направо |
| 2 | унарные `!` `~` `+` `-`, `await` | справа налево |
| 3 | `*` `/` `%` | слева |
| 4 | `+` `-` | слева |
| 5 | `<<` `>>` | слева |
| 6 | `<` `<=` `>` `>=` | слева |
| 7 | `==` `!=` | слева |
| 8 | `&` | слева |
| 9 | `^` | слева |
| 10 | `\|` | слева |
| 11 | `&&` | слева, с сокращением |
| 12 | `\|\|` | слева, с сокращением |

Операнды вычисляются слева направо. Скобки группируют: `(a + b) * c`.

### 7.2 Типизация операторов

Оба операнда бинарного оператора должны иметь **один и тот же тип** (`E201` при несовпадении).

| Оператор | Допустимые типы | Результат |
|---|---|---|
| `+` | `int`, `float`; `string` (конкатенация) | тот же тип |
| `-` `*` `/` `%` | `int`, `float` | тот же тип |
| `<<` `>>` `&` `\|` `^` | только `int` | `int` |
| `<` `<=` `>` `>=` | `byte`, `int`, `float`, `string` | `bool` |
| `==` `!=` | `void`, `bool`, `byte`, `int`, `float`, `string`, `enum`, а также `struct`/`option`/`result`, состоящие из сравнимых типов | `bool` |
| `&&` `\|\|` | `bool` | `bool` |
| унарный `!` | `bool` | `bool` |
| унарный `~` | `int` | `int` |
| унарный `-` | `int`, `float` | тот же тип |
| унарный `+` | `int`, `float` | тот же тип |

Подробности поведения:

- целочисленное деление округляет к нулю, остаток `%` имеет знак делимого; деление на ноль и переполнение — аварийная остановка процесса;
- у `float` деление на ноль недопустимо, результат всегда конечен;
- сдвиг: величина 0–63; `<<` сохраняет младшие 64 бита, `>>` арифметический;
- `<`/`>` для строк сравнивают по Unicode-кодам без локали;
- коллекции и capability через `==` не сравниваются (`E201`).

### 7.3 Литералы

`42`, `0xFF`, `2.5`, `"текст"`, `true`, `false`, `()`.

### 7.4 Имена

Имя — локальная переменная, параметр, глобальное значение модуля, `link`, либо (в позиции члена) алиас модуля/имя типа. Неизвестное имя — `E222`. Имена модулей, типов и пространств **не являются значениями** и не вызываются как функции.

### 7.5 Доступ к полю и члены

```meta
module test.program;
struct Reading { temperatureC: float; rpm: int; }
fn main() -> void {
    let r = new Reading(temperatureC: 90.0, rpm: 3000);
    let t = r.temperatureC;
    let values: array<int> = [1, 2, 3];
    let n = values.length;
}
```

- поля `struct` и DTO читаются `выражение.поле`;
- `.length` (тип `int`) есть у `array`, `list` и `string` (для строки — число Unicode-символов, байты считает `text.byteLength`);
- `Тип.Вариант` — значение `enum`;
- `алиас.ИМЯ` — публичная `const` другого модуля;
- несуществующий член — `E225`; обращение к непубличному члену чужого модуля — `E229`.

### 7.6 Индексация

`выражение[индекс]` — только `array<T>` и `list<T>`, индекс обязан быть `int`, отрицательные индексы не отсчитываются с конца. Результат — `T`. Для `map` индексации нет.

### 7.7 Вызовы

```meta
module test.program;
import meta.system;
import meta.text;
fn double(x: int) -> int { return x * 2; }
fn main() -> void {
    let y = double(21);                       // функция своего модуля
    system.log(text.fromInt(y));              // функция встроенного модуля через алиас
    let list_: list<int> = new list<int>();
    list_.push(1);                            // метод коллекции
}
```

Что можно вызвать:

| Форма | Что вызывается |
|---|---|
| `имя(…)` | функция текущего модуля |
| `алиас.имя(…)` | `pub fn` импортированного модуля или встроенная функция (`system`, `text`, `numeric`, `app`) |
| `значение.метод(…)` | метод коллекции (`list`, `map`) или метод capability, пришедшего от `link` |
| `await …` | асинхронный вызов (см. раздел 11) |

Число и типы аргументов проверяются (`E227`, `E201`). Вызвать значение, не являющееся функцией, нельзя (`E222`).

### 7.8 Литерал массива

```meta
module test.program;
fn main() -> void {
    let a = [1, 2, 3];                   // array<int>
    let b: array<float> = [1.0, 2.5];
    let c: array<int> = [];              // пустой требует ожидаемого типа
}
```

Все элементы одного типа. Массив фиксированной длины; создать массив заданной длины можно `new array<T>(длина, значение)`.

### 7.9 Конструктор `new`

| Форма | Результат |
|---|---|
| `new Имя(поле: значение, …)` | значение пользовательского `struct`; **все поля ровно по разу**, порядок свободен |
| `new array<T>(длина, начальное)` | массив из `длина` копий значения |
| `new list<T>()` | пустой список |
| `new map<K, V>()` | пустой словарь |

`new` для `option`, `result`, capability, opaque и DTO запрещён (`E226`). Для структур аргументы обязаны быть именованными (`E228`); для коллекций — позиционными. Неверное число аргументов — `E227`.

```meta
module test.program;
struct Reading { temperatureC: float; rpm: int; }
fn main() -> void {
    let r = new Reading(rpm: 3200, temperatureC: 108.0);
    let zeros = new array<int>(8, 0);
    var names = new list<string>();
    var counts = new map<string, int>();
}
```

### 7.10 Варианты `some`, `none`, `ok`, `err`

```meta
module test.program;
import meta.system;
fn find(x: int) -> option<int> {
    if (x < 0) { return none; }
    return some(x);
}
fn parse(s: string) -> result<int> {
    if (s == "") { return err(system.error(ErrorCode.InvalidArgument, "пусто")); }
    return ok(1);
}
fn main() -> void { }
```

- `some(e)`, `ok(e)`, `err(e)` — встроенные конструкторы с одним аргументом, `none` — без аргументов;
- тип выводится из ожидаемого типа (возврат, объявление, аргумент); без него — `E203`;
- `err` принимает значение типа `Error`, создаваемое `system.error(код, сообщение)`;
- `ok(())` / `result<void>`: в позиции «пустого» успешного значения пишут `ok(())`.

### 7.11 `await`

`await вызов` — унарный оператор. Операндом может быть только вызов асинхронной функции или асинхронного метода устройства. Подробно — [раздел 11](#11-асинхронность-async-await-yield).

## 8. `option`, `result` и `match`

### 8.1 Синтаксис

```text
match (выражение) {
    шаблон => { … }
    шаблон => { … }
}
```

- тело каждой ветви — **блок**; запятых между ветвями нет;
- хотя бы одна ветвь;
- значение разбирается один раз.

### 8.2 Шаблоны

| Шаблон | Для типа | Привязка |
|---|---|---|
| `some(x)` / `some(_)` | `option<T>` | `x: T` |
| `none` | `option<T>` | — |
| `ok(x)` / `ok(_)` | `result<T>` | `x: T` |
| `err(e)` / `err(_)` | `result<T>` | `e: Error` |
| `true`, `false` | `bool` | — |
| `Тип.Вариант` | `enum` (имя типа обязательно) | — |
| `_` | любой | — |

`_` как привязка (`ok(_)`) игнорирует значение, имя привязки видно только в ветви и подчиняется запрету затенения.

### 8.3 Правила полноты

- `match` применим только к `option`, `result`, `enum`, `bool` (иначе `E241`);
- **должны быть перечислены все варианты** либо присутствовать `_` (иначе `E241`, «неполный match»);
- `_` — только последняя ветвь, после неё ветвей быть не может (`E242`);
- повторяющийся вариант — `E242`;
- шаблон другого типа/варианта, лишняя или отсутствующая привязка — `E241`.

```meta
module test.program;
import meta.system;
enum Health { Normal, Warning, Critical }
fn log(h: Health) -> void {
    match (h) {
        Health.Normal => { system.log("норма"); }
        Health.Warning => { system.log("внимание"); }
        Health.Critical => { system.log("критично"); }
    }
}
fn main() -> void { log(Health.Warning); }
```

```meta-error:E241
module test.program;
fn main() -> void {
    let x: option<int> = some(1);
    match (x) { some(y) => { } }
}
```

### 8.3.1 `match` и ветви `return`

Ветви могут возвращать значение. Если функция не-`void`, все пути должны завершаться `return`: `match` считается завершающим, только когда завершается **каждая** его ветвь.

### 8.4 Типичный разбор ошибок

```meta
module test.program;
import meta.system;
import meta.files;
link data: FileStore = "data";

async fn main() -> void {
    let loaded = await data.readText("config/mode.txt");
    match (loaded) {
        ok(value) => { system.log("mode=" + value); }
        err(problem) => { system.log(problem.message); }
    }
}
```

У `Error` три поля: `code: ErrorCode`, `message: string`, `retryAfterMs: int`.

## 9. Модули, импорт и видимость

### 9.1 `import`

```text
import полное.имя.модуля;
import полное.имя.модуля as алиас;
```

- без `as` алиас — **последний сегмент** имени: `import meta.system;` даёт алиас `system`;
- имена импортируемых модулей: встроенные (`meta.system`, `meta.text`, `meta.numeric`, `meta.files`, `meta.doors`, … — список в [приложении A](#приложение-a-каталог-api-устройств-и-модулей)) или модули того же проекта/зависимостей;
- алиас не может совпадать с другим объявлением модуля, локальной или глобальной переменной, `link` (`E220` / `E211`);
- импорт нужного модуля — отдельная директива на каждый модуль, подстановок (`*`) нет;
- неизвестный модуль — `E303`; циклы импорта запрещены (`E308`).

```meta
module test.program;
import meta.system;
import meta.text as txt;

fn main() -> void {
    system.log(txt.fromInt(7));
}
```

### 9.2 Что даёт алиас

`алиас.имя(...)` вызывает публичную функцию модуля или встроенную функцию. `алиас.ИМЯ` читает публичную константу. `алиас.Тип` — имя типа.

### 9.3 Типы из импортированных модулей

Экспортированные типы можно писать коротким именем:

```meta
module test.program;
import meta.vehicle;
link engine: EngineController = "engine";   // короткое имя
fn main() -> void { }
```

Если два импорта экспортируют одно короткое имя, оно **неоднозначно** (`E224`); тогда пишут полное `vehicle.EngineController` или `мойалиас.Тип`. Неизвестный тип — `E221`.

Без импорта доступны только `Error`, `ErrorCode`, `SampleStamp`.

### 9.4 Экспорт

Из модуля наружу доступны `pub fn`, `pub struct`, `pub enum`, `pub const`. Публичное объявление не может ссылаться на непубличный тип в сигнатуре или полях (`E230`). Обращение к непубличному члену чужого модуля — `E229`.

```meta
module maker.filters;
pub fn smooth(previous: float, current: float, alpha: float) -> float {
    return previous * (1.0 - alpha) + current * alpha;
}
```

Использование из корневого модуля (файлы собираются в один проект):

```text
module test.root;
import maker.filters;
import meta.system;
import meta.text;
fn main() -> void {
    system.log(text.fromFloat(filters.smooth(90.0, 110.0, 0.25)));
}
```

### 9.5 Зависимости и библиотеки

Подключаемая библиотека — отдельный модуль со своим именем; она не получает доступ к устройствам сама: capability передают параметром функции. Зависимости фиксируются lock-данными (пакет, версия, хеш содержимого); недоверенная или повторная зависимость — `E304` / `E305`, неверный lock — `E306`.

## 10. `link` и `watch`: работа с устройствами

### 10.1 `link`

```meta
module test.program;
import meta.doors;
import meta.implants;
link door: Door = "front-door";
link controller: implants.FunctionalController = "function";
fn main() -> void { }
```

- тип обязан быть **capability** (`E223` иначе);
- строка справа — имя **слота** в манифесте установки (`bindings`), а не идентификатор сущности, адрес или пароль; слот не даёт прав сам по себе;
- имя слота должно быть строковым литералом (`E103`) и уникальным в программе (`E220`);
- при запуске handle выдаётся только после проверки прав; если слот не привязан, процесс остаётся в состоянии `BlockedDependency` и `main` не запускается;
- `link` объявляется только в корневом модуле (`E309`) и не может быть `pub`;
- сам `link` в выражении — значение capability: его можно передать параметром функции, но нельзя сохранить в переменную-поле, сравнить, преобразовать в число или строку.

### 10.2 Методы устройства

Методы capability вызывают как обычные: `door.snapshot()`, `await door.setOpen(true)`. Каждый метод имеет вид:

- **Read** — синхронный (`snapshot`, `sample`, `selfTest`), вызывается без `await`;
- **Await** — асинхронный (`setOpen`, `setEnabled`, `flash`), требует `await` внутри `async`-кода.

Возвращают `result<…>`: ошибки (нет питания, отказ в доступе, занято…) приходят как `err(Error)`, а не как исключение. Полный список методов — в приложении A.

### 10.3 `watch`

```meta
module test.program;
import meta.system;
import meta.vehicle;
link ecu: EngineController = "engine";

watch ecu.telemetryChanged(sample) {
    if (sample.temperatureC > 110.0) {
        system.log("перегрев");
    }
}
```

- форма цели строго `имяLink.событие(параметры)`; произвольных условий (`watch (x > 1)`) нет (`E104`);
- число параметров должно совпадать с числом аргументов события (для всех текущих событий — один); тип параметра берётся из каталога API (`E227` при несовпадении);
- несуществующее событие — `E225`; неизвестный `link` — `E222`;
- на одно событие одного `link` допускается один `watch` (`E220`);
- `async watch` может использовать `await`;
- обработчики выполняются по одному: пока выполняется `main` или `watch`, другой не начнётся; `return` завершает только текущий обработчик;
- события доставляются как `Latest` (интересно только последнее значение) или `Ordered` (в порядке, в ограниченной очереди) — это свойство события в каталоге, а не программы;
- пользователь не может сам породить такое событие.

```meta
module test.program;
import meta.system;
import meta.implants;
link neural: NeuralController = "neural";

async watch neural.commanded(command) {
    match (await neural.setEnabled(command.enabled)) {
        ok(applied) => { if (!applied) { system.log("Команда недоступна"); } }
        err(error) => { system.log("Команда отклонена"); }
    }
}

fn main() -> void { system.log("готово"); }
```

## 11. Асинхронность: `async`, `await`, `yield`

### 11.1 Правила

- `async fn` и `async watch` могут содержать `await`;
- возвращаемый тип `async fn` — тип **после** ожидания; типа «задача» в языке нет;
- **каждый асинхронный вызов обязан быть непосредственным операндом `await`**: сохранить его в переменную, отбросить или запустить параллельно нельзя (`E232`);
- `await` вне `async` — `E231`; `await` в инициализаторе глобального значения — `E231`/`E212`;
- вызов асинхронной функции без `await` — `E232`; `await` перед синхронным — `E232`;
- `await` в позиции операнда допустим как `await f(…)`; `await 42` — `E232`.

```meta
module test.program;
import meta.system;
import meta.files;
link data: FileStore = "data";

async fn loadTitle(store: FileStore) -> result<string> {
    return await store.readText("title.txt");
}

async fn main() -> void {
    let title = await loadTitle(data);
    match (title) {
        ok(value) => { system.log(value); }
        err(error) => { system.log(error.message); }
    }
}
```

```meta-error:E231
module test.program;
import meta.doors;
link d: Door = "x";
fn main() -> void { let x = await d.setOpen(true); }
```

```meta-error:E232
module test.program;
import meta.doors;
link d: Door = "x";
async fn main() -> void { d.setOpen(true); }
```

### 11.2 Асинхронный вызов — это команда устройству

`await door.setOpen(true)` ставит валидированную команду в очередь; игровая система при исполнении повторно проверяет права. `ok(state)` обычно означает, что намерение принято, а не что дверь уже открылась: завершение наблюдают по событию или повторным `snapshot`.

### 11.3 `yield`

`yield;` приостанавливает активацию до следующего тика, давая другим обработчикам и игре ход. Это не «сон на N миллисекунд». Все лимиты (gas, длительность активации) продолжают накапливаться: цикл с `yield` всё равно будет остановлен как «бегущий без конца».

```meta
module test.program;
fn main() -> void {
    var n: int = 0;
    while (n < 3) {
        n = n + 1;
        yield;
    }
}
```

Для многосуточной автоматики используют короткие `watch`, а не вечный `main`.

## 12. Константы и инициализаторы глобальных значений

### 12.1 `const`

В `const` допустимы только значения, вычисляемые компилятором **без запуска функций**:

- литералы, `enum`-варианты, ранее объявленные `const`;
- унарные и бинарные операторы над ними (`+ - * / % << >> & | ^ ! ~ && || == != < <= > >=`, конкатенация строк);
- конструктор `new Struct(поле: …)` с константными аргументами;
- доступ к полю константной структуры.

Массивы, списки, словари, вызовы функций, чтение `var`/`let`, `await` в `const` недопустимы — `E216`.

```meta
module test.program;
const BASE: int = 100;
const LIMIT: int = BASE * 2 + 1;
const NAME: string = "A" + "B";
struct Range { low: int; high: int; }
const R: Range = new Range(low: 1, high: LIMIT);
const TOP: int = R.high;
fn main() -> void { }
```

```meta-error:E216
module test.program;
const a: array<int> = [1, 2];
fn main() -> void { }
```

Арифметическая ошибка при вычислении (`1 / 0`, переполнение) — `E204`; цикл между константами — `E213`; слишком долгое вычисление — `E409`.

### 12.2 Глобальные `let` и `var`

Инициализатор глобального `let`/`var` может использовать литералы, константы, другие глобальные значения и конструкторы (`new …`), но **не вызовы функций и не `await`** (`E212`). Значения вычисляются в порядке зависимостей; зависимость по кругу — `E213`.

```meta
    }
}
```

## 16. Формальная грамматика (EBNF)

Грамматика сверена с рекурсивным парсером (`Parser.cs`). Терминалы — в кавычках; `{ X }` — повторение, `[ X ]` — необязательность. `IDENT` исключает ключевые слова и `_`.

```ebnf
program       = "module", qualifiedName, ";", { importDecl }, { declaration } ;
qualifiedName = IDENT, { ".", IDENT } ;
importDecl    = "import", qualifiedName, [ "as", IDENT ], ";" ;
declaration   = globalDecl | functionDecl | structDecl | enumDecl | linkDecl | watchDecl ;
globalDecl    = [ "pub" ], "const", IDENT, ":", type, "=", expression, ";"
              | ( "let" | "var" ), IDENT, ":", type, "=", expression, ";" ;
functionDecl  = [ "pub" ], [ "async" ], "fn", IDENT, "(", [ parameters ], ")",
                "->", type, block ;
parameters    = parameter, { ",", parameter } ;
parameter     = IDENT, ":", type ;
structDecl    = [ "pub" ], "struct", IDENT, "{", { fieldDecl }, "}" ;
fieldDecl     = IDENT, ":", type, ";" ;
enumDecl      = [ "pub" ], "enum", IDENT, "{", IDENT, { ",", IDENT }, [ "," ], "}" ;
linkDecl      = "link", IDENT, ":", typeName, "=", STRING, ";" ;
watchDecl     = [ "async" ], "watch", IDENT, ".", IDENT, "(", [ names ], ")", block ;
names         = IDENT, { ",", IDENT } ;
type          = primitive | typeName | singleType | mapType ;
primitive     = "void" | "bool" | "byte" | "int" | "float" | "string" ;
typeName      = qualifiedName ;
singleType    = ( "array" | "list" | "option" | "result" ), "<", type, ">" ;
mapType       = "map", "<", type, ",", type, ">" ;
block         = "{", { statement }, "}" ;
statement     = localDecl | ifStmt | whileStmt | forStmt | matchStmt | returnStmt
              | "break", ";" | "continue", ";" | "yield", ";" | simpleStmt | block ;
localDecl     = ( "let" | "var" ), IDENT, [ ":", type ], "=", expression, ";"
              | "const", IDENT, ":", type, "=", expression, ";" ;
ifStmt        = "if", "(", expression, ")", block, [ "else", ( block | ifStmt ) ] ;
whileStmt     = "while", "(", expression, ")", block ;
forStmt       = "for", "(", "let", IDENT, "in", expression, ")", block ;
matchStmt     = "match", "(", expression, ")", "{", matchArm, { matchArm }, "}" ;
matchArm      = pattern, "=>", block ;
pattern       = ( "some" | "ok" | "err" ), "(", binding, ")"
              | "none" | "true" | "false" | qualifiedName | "_" ;
binding       = IDENT | "_" ;
returnStmt    = "return", [ expression ], ";" ;
simpleStmt    = expression, [ "=", expression ], ";" ;
expression    = logicalOr ;
logicalOr     = logicalAnd, { "||", logicalAnd } ;
logicalAnd    = bitOr, { "&&", bitOr } ;
bitOr         = bitXor, { "|", bitXor } ;
bitXor        = bitAnd, { "^", bitAnd } ;
bitAnd        = equality, { "&", equality } ;
equality      = relation, { ( "==" | "!=" ), relation } ;
relation      = shift, { ( "<" | "<=" | ">" | ">=" ), shift } ;
shift         = additive, { ( "<<" | ">>" ), additive } ;
additive      = product, { ( "+" | "-" ), product } ;
product       = unary, { ( "*" | "/" | "%" ), unary } ;
unary         = ( "!" | "~" | "+" | "-" | "await" ), unary | postfix ;
postfix       = primary, { ".", IDENT | "[", expression, "]" | "(", [ arguments ], ")" } ;
arguments     = expression, { ",", expression } ;
primary       = INTEGER | FLOAT | STRING | "true" | "false" | IDENT | "none"
              | ( "some" | "ok" | "err" ), "(", expression, ")"
              | "(", [ expression ], ")"
              | "[", [ arguments ], "]"
              | "new", type, "(", [ constructorArgs ], ")" ;
constructorArgs = namedArgs | arguments ;
namedArgs     = IDENT, ":", expression, { ",", IDENT, ":", expression } ;
```

Замечания к грамматике:

- парсер разбирает синтаксис шире, чем допускает смысл: например, `new` с позиционными и именованными аргументами разбирается, а запрещается семантикой (`E228`); `pub` перед `link`/`watch`/`async struct` отвергается на разборе (`E102`);
- в позиции типа `>>` разделяется на две `>`; в выражениях это оператор сдвига;
- `match`-шаблон `Тип.Вариант` читается как `qualifiedName` из идентификаторов через точку;
- имя в позиции `watch` — идентификатор, а не ключевое слово: `watch door.requested(...)`;
- цепочки сравнения (`a < b < c`) разбираются слева, но по типам не проходят.

## 17. Расхождения со спецификацией и оговорки

Проектная спецификация (`Specification.md`, §2) описывает язык «Hybrid 1.0» шире, чем нужно для разбора. Ниже — то, что важно знать при чтении обоих документов; реализация компилятора приоритетна.

1. **Выведение типов.** Спецификация допускает выводить тип локального `let`/`var` из инициализатора; компилятор так и делает. Для локальной `const` тип обязателен (`E203`).
2. **`main`.** Допускаются `fn main() -> void` и `async fn main() -> void`; наличие `main` не обязательно.
3. **Ключевые слова будущих версий** (`null`, `class`, `throw`, `catch`, `spawn`, `eval`, `unsafe`, `typeof`, `using`) резервируются лексером; конструкций для них нет.
4. **Диагностики.** Спецификация упоминает `FeatureNotImplemented` для неподдерживаемых конструкций; в текущем компиляторе неподдерживаемые слова просто дают `E102`.
5. **Расчёт остатка.** Оператор `%` разрешён для `int` и для `float` (остаток с частным, усечённым к нулю).
6. **Свежесть показаний** (`system.isFresh`) и `SampleStamp` — часть каталога `meta.system`, а не отдельная конструкция языка.
7. **Что проверяет сервер, а не язык.** Права доступа, привязка слотов, лимиты gas и длительности, повторная проверка команд игровой системой — свойства установки и рантайма; они не выражаются синтаксисом.
8. **Исходники примеров** лежали в `Resources/Meta/Examples/*.meta`, но файлы `.meta` попадают под правило `.gitignore` (`*.meta`), и в рабочей копии их может не быть; в истории Git их можно найти в коммите `babdb47993^`. Реальные прошивки лежат в `Resources/Meta/Firmware/*.meta` и `Resources/Meta/Medical/Programmer.meta`.

### 18.1 Функции, `option`, цикл

```meta
module examples.math;
import meta.system;
import meta.text;

fn power(energyJ: float, seconds: float) -> option<float> {
    if (seconds <= 0.0) {
        return none;
    }
    return some(energyJ / seconds);
}

fn main() -> void {
    var energy: float = 0.0;
    var step: int = 0;
    while (step < 5) {
        energy = energy + 250.0;
        step = step + 1;
    }
    let measured = power(energy, 5.0);
    match (measured) {
        some(value) => { system.log(text.fromFloat(value) + " W"); }
        none => { system.log("Неверная длительность"); }
    }
}
```

### 18.2 Массивы и приведение типов

```meta
module examples.arraystats;
import meta.system;
import meta.text;
import meta.numeric;

fn mean(values: array<float>) -> option<float> {
    if (values.length == 0) {
        return none;
    }
    var sum: float = 0.0;
    for (let value in values) {
        sum = sum + value;
    }
    return some(sum / numeric.toFloat(values.length));
}

fn main() -> void {
    let samples: array<float> = [92.0, 96.0, 100.0, 104.0];
    samples[0] = 94.0;
    let average = mean(samples);
    match (average) {
        some(value) => { system.log(text.fromFloat(value)); }
        none => { system.log("Нет измерений"); }
    }
}
```

### 18.3 `struct`, `enum`, `match` по enum

```meta
module examples.readings;
import meta.system;
import meta.text;

struct Reading {
    temperatureC: float;
    rpm: int;
}

enum Health {
    Normal,
    Warning,
    Critical
}

fn classify(reading: Reading) -> Health {
    if (reading.temperatureC >= 120.0) {
        return Health.Critical;
    }
    if (reading.temperatureC >= 105.0 || reading.rpm > 7000) {
        return Health.Warning;
    }
    return Health.Normal;
}

fn main() -> void {
    let sample = new Reading(temperatureC: 108.0, rpm: 3200);
    let health = classify(sample);
    match (health) {
        Health.Normal => { system.log("Норма"); }
        Health.Warning => { system.log("Требуется проверка"); }
        Health.Critical => { system.log("Критическая температура"); }
    }
}
```

```meta
module neural.basic;
import meta.implants;
import meta.system;
link neural:NeuralController = "neural";

// A wearer request still passes native power, cooldown and medical checks.
async watch neural.commanded(command) {
    match (await neural.setEnabled(command.enabled)) {
        ok(applied) => { if (!applied) { system.log("Neural command unavailable"); } }
        err(error) => { system.log("Neural command rejected"); }
    }
}

// Conservative software cutoff. Native thermal protection always remains active.
async watch neural.sampled(sample) {
    if (sample.kind == 4 && sample.heat >= 0.85) {
        match (await neural.setEnabled(false)) {
            ok(stopped) => {}
            err(error) => { system.log("Neural cutoff unavailable"); }
        }
    }
}
fn main() -> void { system.log("Neural basic ready"); }
```

### 18.6 Состояние между событиями

```meta
module examples.functions;
import meta.implants;
import meta.system;
link controller: implants.FunctionalController = "function";
var wasActive: bool = false;

async watch controller.stateChanged(state) {
    if (state.active) {
        wasActive = true;
        match (await controller.setEnabled(true)) {
            ok(current) => {}
            err(error) => { system.log("Native control renewal rejected."); }
        }
    } else if (wasActive) {
        wasActive = false;
        system.log("Native mode inactive.");
    }
}

async fn main() -> void {
    match (controller.snapshot()) {
        ok(state) => {
            if (state.kind == implants.FunctionKind.Biomonitor) {
                match (await controller.pulse()) {
                    ok(current) => { system.log("Native reading requested."); }
                    err(error) => { system.log("Native reading rejected."); }
                }
            } else {
                match (await controller.setEnabled(true)) {
                    ok(current) => { system.log("Native mode requested."); }
                    err(error) => { system.log("Native mode rejected."); }
                }
            }
        }
        err(error) => { system.log("Native controller unavailable."); }
    }
}
```

## Приложение A. Каталог API устройств и модулей

Таблицы сгенерированы из `MetaApiCatalog.Default` (хеш контракта фиксируется в артефакте программы). Каталог принадлежит серверу: программа может пользоваться только перечисленным. «Тип» метода: **Read** — синхронный вызов, **Await** — требует `await` в `async`-коде, **Event** — событие для `watch`. Колонка «Scope» — право, которое проверяется при установке; «Доставка» события: `Latest/1` — хранится последнее значение, `Ordered/N` — упорядоченная очередь из N.

Имена типов в таблицах приведены без префикса `meta.` (`doors.DoorState` = `meta.doors.DoorState`). Внутри программы короткое имя доступно после `import meta.модуль;`.
