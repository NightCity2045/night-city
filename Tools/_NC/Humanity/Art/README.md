# Cyberpsychosis sprite sources

Generated with OpenAI ImageGen for this project, 2026-11-05. Original image retained unmodified.
The six cells are stable / overload / dissociation / acute / recovery / phantom.
Project-generated art is released under CC0-1.0. No external reference artwork was supplied.

Prompt: production SS14 pixel-art atlas, three columns and two rows, each cell a 32x32 logical sprite;
five cybernetic brains (turquoise, amber, orange split, crimson sparks, repaired turquoise) and one
compact charcoal humanoid with cyan eyes. No labels, gradients or frames. Follow-up requested removal
of background and grid lines on genuine transparency, preserving cell positions.

`../normalize_sprites.py` splits the 1536x1024 source using nearest-neighbor sampling and binary alpha.
